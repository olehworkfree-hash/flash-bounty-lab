# FLASH: публикация подготовленного фильтра — 10.09.2026

Код объединяет проверку времени ожидания RPC и точные трёхшаговые маршруты.
Перед публикацией повторно выполнены 180 Python-тестов: все прошли.
Результаты нового CI и форка нужно проверять отдельно по фактическим журналам.

Фильтр отбрасывает маршрут только если оптимистическая граница возврата не
покрывает заём и комиссию. Положительная граница ещё не означает прибыль.
Отчёт сохраняет различие между границами, полученными котировками и исполнением.
При отрицательных границах остаётся одна диагностическая котировка для форка.

Это исследовательская ветка, не production-бот. Основная ветка не изменяется.
Кошелёк, ключи и настоящие средства не используются. Расчётный результат не
записывается как заработок. Исторические данные внутри evidence не являются
свежими измерениями. Подробности — docs/TRIANGLE_BOUNDS.md.
